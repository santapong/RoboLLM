| Symptom and context | Supported cause | Corrected procedure and verification |
|---|---|---|
| Red box intersected the base before a trial | Initial mat origin was inconsistent with the selected 90-degree yaw | Define one mat-to-base transform; the provisional origin is now `(0.25, -0.09, 0)` m. Check the reset scene for contacts and compare independent FK with MuJoCo before experiments. |
| Downward grasp targets were rejected | The provisional wrist datum and clearance left the target outside the bounded five-axis workspace | Keep position-first reaches, use feasible downward goals and reject remaining targets. The demonstration uses a provisional wrist datum and 50 mm transit height; these must be remeasured on hardware, not copied as calibration. |
| Lowering a lifted box was rejected by path checks even though current contacts were valid | Planning treated the carried box as stationary in the world | Predict the observed object-to-tool transform only in temporary collision-check data. Keep the actual box free in MuJoCo. A regression test checks that prediction never mutates the live object; the contact-based pick/place test verifies lift and release. |
| FreeCAD command returned without executing the builder | This portable command runtime did not execute the file as `__main__` | Use explicit `ELEXHUB_CAD_DESCRIPTOR` as the builder entry trigger. The CLI exports then reopens FCStd and STEP, checking 23 valid solids, volume and placements. |
| Worktree initially showed mode-only changes on the `/mnt/data` mount | Executable-bit reporting differs on this filesystem | Use worktree-scoped `core.fileMode=false`; do not modify the research checkout. Ruff EXE002 is explicitly excluded only for this mount's executable-bit artifact. Other lint checks remain active. |
| All conditions succeeded and B/C errors were identical | The frozen synthetic suite reaches a ceiling at 15 mm; the compensated residuals are already small | Preserve the suite, labels and results. Report continuous errors and no demonstrated C gain. A future stress/physical suite needs a new identity, not a retrospective threshold change. |
