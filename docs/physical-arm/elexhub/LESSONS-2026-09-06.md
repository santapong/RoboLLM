## Photo-referenced CAD workflow · checked 2026-09-07

Observed in this worktree based on `299664b`, with FreeCAD 1.1.3, MuJoCo 3.10.0, trimesh and mapbox-earcut 2.0.0. Input evidence is the owner-confirmed Elexhub black kit and the linked product photographs, not measured geometry. | Observed symptom/context | Supported cause and repeatable procedure |
|---|---|
| FreeCAD command export had no persistent part colors | The command runtime had no `ViewObject`; calling `Gui.setupWithoutGUI()` still left `GuiUp=0` in the checked runtime. Use `run.py cad --freecad /mnt/data/.cache/elexhub-freecad/squashfs-root/AppRun --gui-colors`. This invokes the GUI offscreen and quits after completion. Reopen both FCStd and STEP; do not infer display-color preservation from a successful CLI exit. |
| Reopened CAD color 0.1 became 0.10196078 | Saved view colors use 8-bit channels. Validate within half of a 1/255 channel step; the original 1e-5 tolerance incorrectly rejected a correctly stored color. Current validation reports colors saved and reopened for 283 solids. |
| FreeCAD printed an exception yet returned exit 0, leaving an older success report | Each invocation now supplies a unique build identity and requires a matching report. A stale report is not proof of this run; also compare its descriptor SHA-256 with the exported descriptor. |
| Longer photo-guided fingers changed the working tabletop geometry | Old reachable poses and fixed closure were insufficient. For the current estimated claw, the mat origin is `(0.23, -0.09, 0)` m, transit TCP height 52 mm; grasp height follows fingertip clearance and closure follows object width/opening. These are provisional scene parameters, not hardware calibration. |
| A grasp/lift diagnostic showed changing wrist roll | The previous downward target was a roll flip outside the bounded wrist range and left yaw unweighted. The attainable pitch-down target `diag(-1,1,-1)` with consistent orientation weights passed the independent orientation and contact pick/place checks. Preserve unchanged collision, lift and success tolerances. |
| Similar kits publish different dimensions and part counts | The 7 September research found 64/65 mm catalog U-brackets and a related ROT3U with different claw/base assembly. Keep supplier specifications separate from owner measurements; bracket outer dimensions are not joint-center spacing. Do not fill measured fields from appearance similarity. |

One original solid description now feeds native CAD features, visual meshes, MuJoCo, URDF and the browser viewer. Real plate holes use triangulated outlines; FreeCAD uses editable sketches/extrusions and bored solids. Meshes are visual-only and add no mass. Verify body frames independently against MuJoCo and CAD world bounds; a 0.15 mm tessellation allowance establishes export consistency, not physical accuracy. Keep the current sliding-jaw approximation explicit until the actual claw linkage is measured.
